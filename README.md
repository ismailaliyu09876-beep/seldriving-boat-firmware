# seldriving-boat-firmware
ESP32-based autonomous surface vessel (ASV) firmware featuring sensor fusion (MPU6050 + QMC5883P), Madgwick AHRS, gain-scheduled PID heading control, differential thrust with L298N, HC-SR04 obstacle detection, and a built-in WiFi web dashboard for telemetry and control. Includes AUTO/MANUAL modes with manual calibration offsets.
